# Robotics Learning Platform — Curriculum Roadmap

**English | [Türkçe](LEARNING_PATH.tr.md)**

The [live platform](https://robotik-platform.vercel.app/) is a **Turkish-language** product. This page provides an English map of its learning structure, **not English translations of the site's 94 lessons**.

## Learning sequence

1. Open the [platform](https://robotik-platform.vercel.app/).
2. Choose a level: middle school, high school, or university/engineering.
3. Follow the site's prerequisites and interactive lessons in their recommended order.
4. Predict outcomes before interacting, then compare the observations with the explanation.
5. Use the search, glossary, and laboratories to revisit difficult concepts.

## Eight curriculum tracks

| Track | Focus |
| --- | --- |
| A | Fundamentals |
| B | Motion, coordinate transformations, and kinematics |
| C | Path planning and motion constraints |
| D | Robot programming languages: RAPID, KRL, Mecademic, FANUC TP, ROS 2 |
| E | Communication and integration |
| F | Perception: sensors and vision |
| G | Simulation and digital twins |
| H | Safety and industrial practice |

The track names summarize the curriculum. For the full content structure, see the [curriculum document](docs/01-mufredat.md) (Turkish). For the software architecture, read [the architecture guide](docs/02-mimari.md) (Turkish) and inspect `lib/robotics/`.

A complete English lesson experience would require a separate localization of the website, UI, and MDX content.
